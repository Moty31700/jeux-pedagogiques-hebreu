🔬 Analyse morphologique des mots-clés

1. רוֹצִים — rotsím (« ils veulent »)

  • Racine : ר-צ-י
  • Binyan : Paʿal (קַל)
  • Forme : participe présent masculin pluriel — sert aussi de présent en hébreu moderne
  • Base : רוֹצֶה (singulier masc.) → רוֹצִים (pluriel masc.)

2. הִתְנַתְּקוּתִי — hitnatkutí (« mon détachement »)

  • Racine : נ-ת-ק (couper, déconnecter)
  • Binyan : Hitpaʿel (הִתְפַּעֵל) — exprime une action réfléchie ou réciproque
  • Forme nominale : infinitif substantivé הִתְנַתְּקוּת + suffixe possessif 1ère pers. sg. י-
  • Sens : « le fait de me déconnecter / mon isolement »

3. לְסַפֵּק — lesapék (« fournir, satisfaire »)

  • Racine : ס-פ-ק
  • Binyan : Piʿel (פִּעֵל) — souvent causatif ou intensif
  • Forme : infinitif construit
  • Contexte : לְסַפֵּק תְּשׁוּבוֹת = « fournir des réponses »

4. מְחַיֵּיךְ — mekhayyékh (« souriant »)

  • Racine : ח-י-כ (sourire)
  • Binyan : Piʿel (פִּעֵל)
  • Forme : participe présent masculin singulier
  • Note : verbe employé sans complément direct — le sourire est ici une performance sociale forcée

5. שׁוֹמַעַת — shomáʿat (« tu entends / elle entend »)

  • Racine : ש-מ-ע (entendre, écouter)
  • Binyan : Paʿal (קַל)
  • Forme : participe présent féminin singulier (= présent en hébreu moderne)
  • Contexte : apostrophe intime à une femme — question rhétorique chargée d'émotion

✏️ Exercices de compréhension

Exercice 1 — Vrai ou Faux ?

D'après le court extrait :

מְחַיֵּיךְ אֲבָל זֶה נֶטוֹ תַּחְפּוּשׁוֹת

(mekhayyékh aval ze neto takhpushót)

  1. Le chanteur sourit parce qu'il est vraiment heureux.
  2. Le sourire est décrit comme un pur déguisement.
  3. Le mot נֶטוֹ signifie « parfois ».

Exercice 2 — Traduction

Traduisez ces expressions tirées des paroles :

  1. לְסַפֵּק תְּשׁוּבוֹת לְאַף אֶחָד (lesapék tshuvot leaf ekhad)
  2. רַק מִפַּחַד (rak mipákhad)
  3. גַּם כְּשֶׁאֵין אוֹתִי הַיּוֹם (gam kshe-eyn otí hayóm)

Exercice 3 — Complétion de phrase

Choisissez le mot manquant dans cette phrase tirée des paroles :

בְּסְטוֹרִי ___ אֲבָל זֶה נֶטוֹ תַּחְפּוּשׁוֹת

a) בּוֹכֶה (bokhé) b) מְחַיֵּיךְ (mekhayyékh) c) שׁוֹמֵעַ (shomáʿ)
