🔬 Analyse morphologique des mots-clés

1. בּוֹכֶה (bokhe) — « pleure »

  • Racine : ב-כ-י
  • Binyan : פָּעַל (Qal)
  • Forme : participe présent, masculin singulier
  • Structure : הָעָנָן בּוֹכֶה = « le nuage pleure » → sujet inanimé poétisé (personnification)

2. שׁוֹחֶה (sokhe) — « nage »

  • Racine : ש-ח-י
  • Binyan : פָּעַל (Qal)
  • Forme : participe présent, masculin singulier
  • Remarque : verbe à finale faible (ל"י), la yod disparaît dans certaines formes

3. עָפִים (afim) — « volent »

  • Racine : ע-ו-פ (racine médiane faible, פ"ו)
  • Binyan : פָּעַל (Qal)
  • Forme : participe présent, masculin pluriel
  • Accord : avec שְׁלֹשָׁה שְׁחָפִים (trois mouettes, masculin pluriel)

4. תְּגִידִי (tgidi) — « tu diras / tu dis »

  • Racine : נ-ג-ד
  • Binyan : הִפְעִיל (Hifil)
  • Forme : futur (injonctif), 2ᵉ personne féminin singulier
  • Construction : אַל + futur = défense polie : אַל תְּגִידִי = « ne dis pas »
  • Remarque : la chanson alterne אַל תְּגִידִי כֵּן / אַל תְּגִידִי לֹא → refus de tout verdict définitif sur l'amour

5. מְדַבֵּר (medaber) — « parle »

  • Racine : ד-ב-ר
  • Binyan : פִּיעֵל (Piel)
  • Forme : participe présent, masculin singulier
  • Expression : יָם מְדַבֵּר בְּלִי מִלִּים = « la mer parle sans mots » → oxymore poétique

6. מְחַכָּה (mekhaka) — « attend »

  • Racine : ח-כ-י
  • Binyan : פִּיעֵל (Piel)
  • Forme : participe présent, féminin singulier (accord avec אוֹנִיָּה / אֶרֶץ)
  • Construction : לָנוּ שָׁם בָּאֹפֶק מְחַכָּה = « nous attend là-bas à l'horizon »

📝 Exercices de compréhension

Exercice 1 — Vrai ou Faux

Lisez l'extrait : הָעָנָן בּוֹכֶה / אֶל הַיָּם שׂוֹחֶה

  1. Le nuage nage vers la montagne. → Vrai / Faux
  2. Deux verbes de mouvement/action sont utilisés en parallèle. → Vrai / Faux
  3. Le style est réaliste et descriptif. → Vrai / Faux

Exercice 2 — Traduction

Traduisez ces expressions en français :

  1. יָם מְדַבֵּר בְּלִי מִלִּים
  2. עָפִים מֵעַל הַגַּלִּים
  3. כְּמוֹ נְשִׁיקָה
  4. לָנוּ שָׁם בָּאֹפֶק מְחַכָּה

(Corrigé : 1. La mer parle sans mots / 2. Volent au-dessus des vagues / 3. Comme un baiser / 4. Nous attend là-bas à l'horizon)

🧠 Quiz — אֵין מְדִינָה לְאַהֲבָה

1. Dans l'extrait אַל תְּגִידִי כֵּן / וְאַל תְּגִידִי לֹא, à quelle personne grammaticale s'adresse le locuteur ?

a) À lui-même (1ʳᵉ personne) b) À une femme (2ᵉ personne féminin singulier) c) À un groupe (2ᵉ personne pluriel)

2. Dans l'expression יָם מְדַבֵּר בְּלִי מִלִּים, quel binyan est le verbe מְדַבֵּר ?

a) פָּעַל (Qal) b) הִפְעִיל (Hifil) c) פִּיעֵל (Piel)

a) ע-פ-פ b) ע-ו-פ c) פ-ע-ל

4. Dans les paroles, à quoi sont comparées les fleurs fermées (פְּרָחִים יָפִים סְגוּרִים) ?

a) À un nuage b) À un bateau c) À un baiser

5. Quel animal n'est PAS mentionné dans la chanson ?

a) שַׁחַף (mouette) b) פַּרְפַּר (papillon) c) דָּג (poisson)

a) ב-כ-ה b) ב-כ-י c) ב-כ-כ
